# __NAME__

A design lab built on Lab kit. Use the `/lab` skill for any work here: a new
lab, a new round, options, dials, or a pick.

- A lab is a file in `src/features/`, numbered to hold the rail's order.
- Dev: `npm run dev` (port __PORT__). Shared state: `npm run serve`, then
  `server: "/__lab"` in `src/main.tsx`.
- Update the frame: `npm update lab-kit`.
